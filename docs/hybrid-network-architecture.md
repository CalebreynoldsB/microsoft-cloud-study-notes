# Enterprise Hybrid Networking & Security Architecture 🌐🛡️

This document maps core enterprise networking concepts from Cisco Systems (**200-301 CCNA, 350-401 ENCOR**) to Microsoft Azure Administrator & Security practices (**AZ-104, AZ-500**).

---

## 🔀 Technology Mapping & Concept Translation

| Infrastructure Domain | Cisco Enterprise Infrastructure (200-301 / 350-401) | Azure Security & Administration (AZ-104 / AZ-500) |
| :--- | :--- | :--- |
| **Routing Protocol** | BGP (Border Gateway Protocol) / OSPF | Azure Dynamic Routing & ExpressRoute BGP Peering |
| **Network Segmentation** | VLANs & VRF (Virtual Routing and Forwarding) | Azure Virtual Networks (VNets) & Subnets |
| **Traffic Filtering** | Extended Access Control Lists (ACLs) / ASA Firewall | Network Security Groups (NSGs) & Azure Firewall |
| **Site-to-Site Tunneling** | IPsec VPN / GRE Tunnels / DMVPN | Azure VPN Gateway (Route-based IPsec/IKE) |
| **Zero Trust Access** | Cisco ISE (Identity Services Engine) 802.1X | Microsoft Entra ID Conditional Access & PIM |
