# Microsoft Azure Fundamentals (AZ-900) Exam Resources & Study Guide

This document aggregates core cloud concepts, service categories, and exam preparation strategies for the **Microsoft Azure Fundamentals (AZ-900)** certification.

---

📌 Core Domain & Cloud Fundamentals Breakdown

To pass the AZ-900 exam, candidates should possess a solid conceptual understanding of cloud computing models and Azure architectural components:

1. **Cloud Concepts:**
   * **Cloud Models:** Public, Private, and Hybrid Cloud trade-offs.
   * **Service Models:** IaaS (Virtual Machines) vs. PaaS (App Service, SQL Database) vs. SaaS (Microsoft 365).
   * **Financial Benefits:** Shifting from Capital Expenditure (CapEx) to Operational Expenditure (OpEx) with a consumption-based model.

2. **Azure Architecture & Core Services:**
   * **Resource Organization:** Management Groups -> Subscriptions -> Resource Groups -> Resources.
   * **Global Infrastructure:** Regions, Region Pairs, and Availability Zones for High Availability (HA).
   * **Storage & Networking:** Blob Tiers (Hot, Cool, Cold, Archive), Virtual Networks (VNets), and VPN/ExpressRoute gateways.

3. **Management, Governance & Security:**
   * **Identity:** Microsoft Entra ID (authentication, authorization, and RBAC controls).
   * **Governance Tools:** Azure Policy (enforcing compliance) and Resource Locks (`CanNotDelete` vs. `ReadOnly`).
   * **Cost Control:** Azure Cost Management, Spending Limits, and Total Cost of Ownership (TCO) Calculator.

## 💡 Practical Preparation Tips

* **Understand IaaS vs. PaaS vs. SaaS**: Always ask "Who manages the underlying OS and runtime?" to determine the correct cloud service model.
* **Pay Attention to Governance**: Questions frequently test the exact difference between an Azure Policy (enforcement/audit) and an RBAC role (permissions).
* **Pacing**: With 35–55 foundational questions over 45 minutes, read carefully—especially on the non-reversible "Yes/No" scenario sets!
